基础样式规范

面向产品与前端实现的基础样式参考。这里展示颜色 Seed、排版、间距、几何、控件、图标和动效，不包含任何具体系统页面。

本页是静态样式预览。正式 Vue 界面遵循 Ant Design Vue 官方主题 API：使用 ConfigProvider theme 设置 Seed Token 和算法，并用 theme.useToken() 获取当前主题的派生值；本页的派生色样例不构成额外 Seed 或运行时算法输出。

01 / Color

颜色与 Seed Tokens

所有颜色从统一 Seed 起源。主题算法负责浅色、深色、悬停、背景、边框与文字等派生值。

阅读正文样式

知识内容应保持轻松、连续的阅读节奏。正文采用 16px 字号与 1.8 行高，标题层级和段落间距提供稳定的视觉锚点。

界面字体

MiSans · 界面主字体 / MiSans L3 · 级别 3 字符补充"MiSans", "MiSans L3", -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", sans-serifMiSans 覆盖 GB18030-2022 实现级别 1、2；MiSans L3 提供级别 3 字符（60,340 个），不包含级别 1、2 字符，需与 MiSans 配合。L3 仅支持 Regular 字重，其他字重由 MiSans 提供。需部署并加载对应字体文件，未命中字形时浏览器按字体栈回退。生僻字预览：𠖜 𠖝 𠖞 𠖟

04 / Shape & Elevation

圆角、边框与阴影

标准控件使用 6px 圆角，内容卡片与浮层使用 8px 至 12px；边框保持轻量。
